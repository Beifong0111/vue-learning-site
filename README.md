# 📘 Vue 单词练习网站（Vue.js 学习站点）

这是一个基于 Vue 3 的网页项目，旨在帮助你复习和记忆 Vue.js 的常用语法，以及日语相关词汇。页面以课程方式呈现知识点，支持展开/收起每课内容查看示例代码与说明。

## ✨ 项目功能

- ✅ 分章节查看 Vue 教程（支持 1～30+ 课）
- ✅ 每课配有语法说明与高亮代码片段
- ✅ 响应式设计，适配桌面与移动浏览器
- ✅ 点击标题展开/收起课程内容
